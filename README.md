# blin4iki

Калькулятор блинов на молоке с водой (классический рецепт, без разрыхлителя).

Пересчёт в трёх режимах: по объёму теста, по количеству молока и по количеству муки. Все количества в граммах и миллилитрах, с указанием температуры ингредиентов. Светлая и тёмная темы.

Страница: https://ncuxodejluk-code.github.io/blin4iki/
